"# Technogrowth-Backend" 
🌱 Technogrowth
Technogrowth is a backend-driven project designed to support smart automation and growth monitoring systems. Built with Flask and integrated with MongoDB Atlas, it enables seamless data collection, sensor management, and alert handling. The project focuses on scalability, clean API design, and smooth integration with modern frontend frameworks like React/Vite.

Key features:

🔧 RESTful API endpoints for sensor data, growth tracking, and alerts

📊 MongoDB Atlas integration for cloud-based storage and analytics

⚡ Environment variable support for secure configuration

🔄 Easy integration with IoT devices and frontend dashboards
